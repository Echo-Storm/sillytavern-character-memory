# tools/

Scratch/notes branch for the CharMemory fork effort — no shared history with `beta`,
`master`, or any of the `fix/*`/`feature/*` branches, on purpose. This is where
non-code housekeeping lives so it never appears in a diff sent upstream.

- `PROJECT-NOTES.md` — start here. Branch map, remotes, live test setup, key decisions.
- `AUDIT-NOTES.md` — full codebase audit: architecture map, ranked findings.

Add future test scripts, scratch data, or session notes here too.
